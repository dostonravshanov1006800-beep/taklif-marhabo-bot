Браузерные сценарии мини-аппа (Playwright). Запуск: сервер как у Pages
(python3 pages_srv.py docs 8834, префикс /taklif-marhabo-bot), затем `python3 tests/wizard/<файл>.py`.
Форма устроена как мастер из 5 шагов: поля лежат на шагах (1 стиль, 2 имена/дата/место, 3 медиа,
4 тексты, 5 подарки/сохранить), поэтому сценарий сначала открывает нужный шаг (точки [data-wzg]).
Дальше шага 2 мастер не пускает без имени и даты.
