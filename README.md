# Marhabo: Telegram-бот + мини-приложение на GitHub

Живёт целиком на GitHub (Actions + Pages). Без сторонних серверов и платных сервисов.

- Бот отвечает на `/start` красивым текстом и синей кнопкой мини-приложения.
- Мини-приложение: шесть шаблонов, программа, личные ссылки гостей, всё хранится в Telegram CloudStorage.
- Ответы гостей («Приду / Не смогу») приходят владельцу в чат с ботом.

## Как работает
- `docs/` публикуется на GitHub Pages (мини-приложение и страница приглашения).
- `bot/bot.mjs` работает в GitHub Actions: long polling ~5,5 часов, затем сам себя перезапускает; cron каждые 20 минут подстраховывает.
- Секрет один: `BOT_TOKEN`.
